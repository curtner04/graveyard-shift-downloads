# Graveyard Shift

Windows playtest installers and update feed.

## Download

[Open the latest release](https://github.com/curtner04/graveyard-shift-downloads/releases/latest) and download the `GS-Setup-...exe` installer under Assets. Close the game normally before running an installer.

The first release will appear after the publishing credential is connected and the next successful installer build completes.

## Updates

Configured builds check for updates when the game starts. If an update is available, the launcher offers to open its installer download. You choose when to install it. Offline play remains available. Older copies need one initial installation of a build with update checking enabled.

Completed scheduled builds are published after the 4:00 AM Eastern installer queue runs; explicitly requested manual installer builds use the same channel.

This repository contains public downloads and release information. Game source code and player saves are not uploaded here.
